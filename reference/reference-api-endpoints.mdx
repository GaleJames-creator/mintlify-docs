## Create a book

The `POST /v2/books` endpoint creates a new book with `PENDING` status. You must finalize a book to make it visible and available to customers in the marketplace.

<Note>To avoid creating duplicates, the request requires an `Idempotency-Key` header with a unique value &mdash; if omitted, retried requests may create duplicate books. Optionally, use `X-Request-ID` to track requests in logs and `X-Publisher-ID` to scope the request to a specific publisher account. See [Add the `Idempotency-Key` header](/how-to-guides/how-to-guides-add-the-idempotency-key-header) for details.</Note>

<IsbnNote />

```bash
curl --request POST \
  --url https://api.bookhub.com/api/v2/books \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: <idempotency-key>' \
  --header 'X-Request-ID: <request-id>' \
  --header 'X-Publisher-ID: <publisher-id>' \
  --data '{
    "title": "The Great Adventure",
    "author": "Jane Smith",
    "description": "An epic tale of courage and discovery",
    "language": "en-US",
    "publisher": "Adventure Books Inc",
    "publishedDate": "2024-03-15",
    "isbn": "978-0-1234-5678-9",
    "price": 24.99,
    "coverImages": [
      "https://covers.bookhub.com/great-adventure-front.jpg",
      "https://covers.bookhub.com/great-adventure-back.jpg"
    ],
    "genres": ["Fiction", "Adventure"],
    "bookFormat": "Hardcover"
  }'
```

Creating a book returns `201 Created`.

## Finalize a book

The `PATCH /v2/books/{bookId}/finalize` endpoint changes book status from `PENDING` or `INACTIVE` to `ACTIVE`, making it visible to customers. A successful finalization returns `200 OK` with the updated book details.

<BookId />

```bash
curl --request PATCH \
  --url https://api.bookhub.com/api/v2/books/{bookId}/finalize \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "notes": "Reviewed and approved by editorial team"
}
'
```

Returns a `200 OK` response with updated status:

```json
{
  "status": "success",
  "message": "Book finalized successfully",
  "data": {
    "bookId": "123e4567-e89b-41d4-a716-426614174000",
    "title": "The Great Adventure",
    "status": "ACTIVE",
    "updatedDate": "2024-03-16T05:31:56Z"
  }
}
```

### Business rules

- Only books with `PENDING` or `INACTIVE` status can be finalized.
- Finalization is **idempotent** (calling it multiple times has the same effect).
- The book becomes available to customers immediately upon finalization.
- Use the `PATCH /v2/books/{bookId}/deactivate` endpoint to revert from `ACTIVE` to `INACTIVE`.

## Get a specific book

The `GET /v2/books/{bookId}` endpoint retrieves details of a single book by its `bookId`. The response includes the `hitCount` field, which tracks how many times the book detail page has been accessed.

<BookId />

```bash
curl --request GET \
  --url https://api.bookhub.com/api/v2/books/{bookId} \
  --header 'Authorization: Bearer <token>'
```

### `hitCount` field explained

The `hitCount` field provides basic analytics:

- **Type**: Integer (minimum 0)
- **Purpose**: Tracks how many times the book detail page has been accessed
- **Updates**: Incremented each time a buyer retrieves the book. Publisher requests do not increment the count.
- **Initial value**: 0 for newly created books
- **Read-only**: Cannot be modified directly via API

### Response headers for getting a specific book

The `GET /v2/books/{bookId}` endpoint includes the following caching headers to support conditional requests:

```bash
ETag: "33a64df551425fcc55e4d42a148795d9f25f89d4"
Cache-Control: max-age=3600, must-revalidate
```

## Get all books

The `GET /v2/books` endpoint retrieves a paginated list of books. A successful response returns `200 OK` with a JSON array of books and pagination metadata.

<Note>
When sending a request to `GET /v2/books`, the following considerations apply:

* Title sorting is not supported. Only `createdDate` sorting is available for the `sort` parameter.
* The `hitCount` field is not included in paginated results. To retrieve `hitCount`, use `GET /v2/books/{bookId}` for each book individually.
</Note>

### Pagination

API `pagination` splits large datasets into smaller, manageable chunks. When you request a list of books (e.g., `GET /v2/books`), the API returns the total number of items, the total number of pages, and the current page. 

The server automatically calculates `totalPages` from `totalItems` and `itemsPerPage`; you do not need to compute it. For example, if there are 250 books and the page size is 100, `totalPages` will be 3. The first two pages will return 100 items each, and the last page will return the remaining 50 items. The `GET /v2/books` endpoint also accepts `status`, `sort`, and `order` parameters. 

```json
{
  "status": "success",
  "data": {
    "books": [
      {
        "bookId": "123e4567-e89b-41d4-a716-426614174000",
        "title": "The Great Adventure",
        "author": "Jane Smith"
      }
    ],
    "pagination": {
      "totalItems": 250,
      "totalPages": 3,
      "currentPage": 1,
      "itemsPerPage": 100
    }
  }
}
```

The query parameters `page` and `limit` control the pagination behavior. The default values are `page=1` and `limit=20`. You can adjust these values to retrieve different pages or change the number of items per page.

### ✅ Valid get all books request

#### Sort by creation date, newest first (default)

```http
GET /v2/books?sort=createdDate&order=desc
```

#### Sort by creation date, oldest first

```http
GET /v2/books?sort=createdDate&order=asc
```

#### No sort parameter (uses default: createdDate desc)

```http
GET /v2/books
```

### Page exceeding total pages (returns empty array)

```http
GET /v2/books?page=10&limit=20
```

Returns `200 OK` with an empty `books` array.

### ❌ Invalid get all books request

#### Out of range (greater than 100)

```http
GET /v2/books?limit=150&page=20
```

Returns a `400` error:

```json
{
  "status": "error",
  "message": "Validation failed",
  "errors": [
    {
      "field": "limit",
      "error": "OUT_OF_RANGE",
      "description": "limit must be between 1 and 100",
      "validation_context": {
        "rule": "max_value",
        "constraint": {
          "maximum": 100
        },
        "provided_value": "150"
      }
    }
  ]
}
```
#### Page below minimum (less than 1)

```http
GET /v2/books?limit=10&page=0
```

Returns a `400` error:

```json
{
  "status": "error",
  "message": "Validation failed",
  "errors": [
    {
      "field": "page",
      "error": "OUT_OF_RANGE",
      "description": "page must be 1 or greater",
      "validation_context": {
        "rule": "min_value",
        "constraint": 
        {
          "minimum": 1
        },
        "provided_value": "0"
      }
    }
  ]
}
```

#### Invalid sort parameter (title sorting removed in v2)

```http
GET /v2/books?sort=title&order=asc
```

Returns a `400` error:

```json
{
  "status": "error",
  "message": "Validation failed",
  "errors": [
    {
      "field": "sort",
      "error": "INVALID_VALUE",
      "description": "sort must be createdDate. Title sorting was removed in v2.",
      "validation_context": {
        "rule": "allowed_values",
        "constraint": {
          "allowed": ["createdDate"]
        },
        "provided_value": "title"
      }
    }
  ]
}
```

### Response headers for get all books

The GET /v2/books endpoint includes response headers, including pagination and rate-limit headers:

| Header | Type | Description |
|--------|------|-------------|
| `X-Total-Count` | Integer | Total number of books matching the filters |
| `Link` | String | Pagination links for next and last pages |
| `X-RateLimit-Limit` | Integer | Maximum requests allowed per minute |
| `X-RateLimit-Remaining` | Integer | Requests remaining in the current window |
| `X-RateLimit-Reset` | Integer (Unix timestamp) | Unix timestamp when the rate limit window resets |

```bash
X-Total-Count: 87
Link: <https://api.bookhub.com/api/v2/books?page=2>; rel="next",
      <https://api.bookhub.com/api/v2/books?page=5>; rel="last"
X-RateLimit-Limit: 150
X-RateLimit-Remaining: 149
X-RateLimit-Reset: 1735128600
```

## Deactivate a book

The `PATCH /v2/books/{bookId}/deactivate` endpoint changes the status of an `ACTIVE` book to `INACTIVE` and removes it from the BookHub marketplace without deleting it. Deactivation is a required step before deleting a book.

<BookId />

```bash
curl --request PATCH \
  --url https://api.bookhub.com/api/v2/books/{bookId}/deactivate \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "notes": "Removed due to publisher request"
}
'
```

Returns a `200 OK` response with updated status:

```json
{
  "status": "success",
  "message": "Book deactivated successfully",
  "data": {
    "bookId": "123e4567-e89b-41d4-a716-426614174000",
    "title": "The Great Adventure",
    "status": "INACTIVE",
    "updatedDate": "2026-07-15T14:55:23Z"
  }
}
```

## Delete a book

The `DELETE /v2/books/{bookId}` endpoint permanently removes `INACTIVE` books from the BookHub marketplace. Deleting a book removes it from search results and future queries, reducing catalog clutter. 

<BookId />

```bash
curl --request DELETE \
  --url https://api.bookhub.com/api/v2/books/{bookId} \
  --header 'Authorization: Bearer <token>'
```

A successful delete returns a `204 No Content` response with no body.

### Business rules

- Only `INACTIVE` books can be deleted.
- A deletion operation cannot be undone.
- `ACTIVE` books must be deactivated before deletion.

## Error codes

Requests that fail field validation include an `errors` array with field-level details. Authentication and rate-limit errors return only the `status` and `message`. Only `POST` and `PATCH` *success* responses include a `message` field. Error responses always include `status` and `message`.

<Note>All endpoints return `401` for invalid tokens, `404` when a `bookId` doesn't exist, and `409` when a duplicate resource (a book with the same ISBN already exists) is detected. Endpoint-specific errors are documented inline.</Note>

| Status code | Meaning                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------- |
| `400`       | Bad request — invalid field value or status transition or missing required Idempotency-Key header. |
| `401`       | Unauthorized — missing or invalid JWT                                                             |
| `404`       | Not found — `bookId` does not exist                                                               |
| `409`       | Conflict — a book with this ISBN already exists.                                                   |
| `429`       | Rate limit exceeded — 150 requests per minute                                                     |
