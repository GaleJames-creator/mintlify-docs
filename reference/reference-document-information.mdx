## Documentation changelog

### July 25, 2026

**API reference (OpenAPI spec)**

* Added response examples to the shared `401 Unauthorized` and `404 Not Found` responses. Previously these had no example of their own, so the docs rendered the unrelated `400` ISBN-validation error body in their place on every endpoint that returned them.
* Added a second `400` example to **Create a book** covering a malformed (non-UUID) `Idempotency-Key`, alongside the existing invalid-ISBN example.
* Corrected the **Deactivate a book** and **Finalize a book** `200` response schemas, which showed a phantom nested `data` object the API never returns.
* Documented the `204 No Content` success response for **Delete a book** in the endpoint description (a 204 has no body, so it renders no example tab).
* Changed the idempotent-replay (`200`) response message on **Create a book** from "Book created successfully" to "Book already created," so it reads distinctly from the `201` created response. *(This is a wording change to the documented response, not a change in API behavior.)*

**Guides and examples**

* Expanded [Add the Idempotency-Key header](/how-to-guides/how-to-guides-add-the-idempotency-key-header) with an error-handling reference table (400/401/409/429) and error handling in the code sample.
* Fixed the Python sample in [Code examples](/reference/reference-code-examples): the create request now includes the required `Idempotency-Key` header.
* Corrected a stale `bookId` example in Step 3 of the [Quickstart](/quickstart/quickstart) to use the standard UUID format.
* Corrected the v2 status from Preview to Current to match the versioning table and release notes.
