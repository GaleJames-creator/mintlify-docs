Use pagination to limit the number of results per page for a `GET /v2/books` request with a large book dataset.

## Prerequisites

<Prerequisites />

* Familiarity with BookHub Publisher API v2.
* A valid JWT for authentication.
* Access to your codebase that integrates with the BookHub Publisher API v2.

## Step 1: Send a paginated request

To implement pagination with the BookHub Publisher API, construct a request that fetches results in pages using the `page` and `limit` parameters.

The following examples use `page` and `limit` only. The endpoint also accepts `status`, `sort`, and `order` parameters — see [Get all books](/reference/reference-api-endpoints#get-all-books) for details.

```python
def fetch_all_books(base_url, token):
    all_books = []
    page = 1
    while True:
        response = requests.get(
            f"{base_url}/v2/books",
            params={'page': page, 'limit': 100},
            headers={'Authorization': f'Bearer {token}'}
        )
        response.raise_for_status()
        data = response.json().get('data', {})
        if 'pagination' not in data:
            break
        all_books.extend(data.get('books', []))
        if page >= data['pagination']['totalPages']:
            break
        page += 1
    return all_books
```

<Note>The loop exits when `page` reaches `totalPages`. If the API returns fewer items than `limit`, stop after processing that page. If the response does not include a `pagination` object, exit immediately.</Note>

### Error handling

The `page` parameter defaults to 1. The `limit` parameter accepts values between 1 and 100 and defaults to 20.

| Code  | Cause                                                          | Resolution                                                 |
|-------|----------------------------------------------------------------|------------------------------------------------------------|
| `400` | Bad request (for example, invalid `page` or `limit` parameter) | Provide a valid `page` or `limit` parameter and try again. |
| `401` | Unauthorized (for example, a missing or invalid JWT)           | Provide a valid JWT and try again.                         |
| `429` | Rate limit exceeded (for example, 150 requests per minute) | Wait until the time in the `X-RateLimit-Reset` header, then retry with the same `Idempotency-Key`. See [Monitor rate limits](/how-to-guides/how-to-guides-monitor-rate-limits). |

## Step 2: Test your implementation

Call the `fetch_all_books` function with your API base URL and JWT. Verify that it retrieves all books across multiple pages by checking the length of the returned list against `totalItems`.

```python
BASE_URL = "https://api.bookhub.com/api"
TOKEN = "YOUR_JWT_TOKEN"
books = fetch_all_books(BASE_URL, TOKEN)
print(f"Total books fetched: {len(books)}")
```
